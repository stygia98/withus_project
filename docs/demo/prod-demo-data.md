# 운영(prod) 시연 데이터 준비 절차 — 발송 구간

> 기준: PRD v2.3 6.4(예시 구조)·8.4(발송 시간)·10.3(완료 기준)·10.4(결정 사항), roadmap W5.
> 담당: 팀원2(발송 구간). 로컬 시드(`db/seed/local/`)는 prod 에서 실행되지 않으므로 이 문서의 절차로 만든다.

## 0. 원칙

- **운영 DB 를 SQL 로 직접 수정하지 않는다.** 모든 데이터는 관리자 화면(또는 공개된 `/api/v1/**`)으로 만든다.
- 기능 동결 이후이므로 **데이터 준비 중 발견한 문제는 버그 수정만** 한다(W5).
- 메일은 **SES 샌드박스**라 인증된 수신 주소로만 도착한다. 시연 고객의 이메일은 모두 인증된 주소여야 한다(PRD 10.4).
- 광고성 메일·SMS 는 08:00~20:50 에만 나간다(8.4). 시연 시각이 이 범위를 벗어나면 다음 날 08:00 까지 보류된다.

## 1. 준비 순서

| 순서 | 만들 것 | 화면 | 비고 |
|---|---|---|---|

| 3 | 쿠폰 2개 | 쿠폰 관리 화면(팀원3) | VIP 쿠폰, 일반 쿠폰. 유효기간이 시연일을 포함해야 한다(워크플로우 검증이 확인) |
| 4 | 템플릿 5개 | `/templates/new` | 아래 2장 표 |

| 6 | 6.4 예시 워크플로우 | `/campaigns/new` → 워크플로우 | 4장 |

## 2. 템플릿 (메일·SMS × 광고·비광고)

| 채널 | 이름 | 광고 여부 | 비고 |
|---|---|---|---|
| EMAIL | 환영 메일 | 광고 | 링크 1개 이상(클릭 추적 확인용) |
| EMAIL | 쿠폰 안내 메일 | 광고 | 본문에 `{{couponUrl}}` 포함 |
| SMS | SMS 리마인드 | 광고 | 본문에 `(광고)`·수신거부 문구를 직접 쓰지 않는다(시스템이 자동 삽입, 8.4) |
| EMAIL | 이용 약관 변경 안내 | 비광고 | `(광고)` 표기가 붙지 않는 것을 확인 |
| SMS | 배송 안내 SMS | 비광고 | `(광고)`·수신거부 문구가 붙지 않는 것을 확인 |

- 본문의 `(광고)`·발신자·수신거부 문구는 직접 입력하지 않는다. 직접 입력하면 저장이 거부된다(backend #57).
- 이름 없는 고객 대비로 치환자는 기본값을 쓴다: `{{name|고객}}`.

## 3. 일회성 캠페인

- 대상: 세그먼트 "서울·경기 구매 10만 원 이상", 템플릿 "쿠폰 안내 메일", 쿠폰 1개 연결.
- 예약 시각은 **08:00~20:50 안**으로 잡는다. 21시 예약이 막히고 가능한 시각이 안내되는지도 한 번 시도해 둔다(10.3 8번째 항목).
- 같은 캠페인을 두 번 실행해도 고객당 한 번만 발송되는지 확인한다(10.3).

## 4. 6.4 예시 워크플로우

PRD 6.4 의 구조를 그대로 만든다. **노드 9개, CONDITION 중첩 2단계**(제한: 15개·2단계).

```
TRIGGER(CUSTOMER_REGISTERED)
 └ SEND_EMAIL(환영 메일)
    └ WAIT(2일)
       └ CONDITION(EMAIL_CLICKED)
          ├ YES → CONDITION(PURCHASE_GTE 100000)
          │        ├ YES → SEND_EMAIL(쿠폰 안내 메일 + VIP 쿠폰) → END
          │        └ NO  → SEND_EMAIL(쿠폰 안내 메일 + 일반 쿠폰) → END
          └ NO  → SEND_SMS(SMS 리마인드) → END
```

- 저장 전 "구조 검사"(validate)로 `valid=true` 를 확인한다. SEND 노드마다 쿠폰을 따로 연결할 수 있다.
- 빌더는 `EMAIL_OPENED` 대신 `EMAIL_CLICKED` 를 권장한다(Apple Mail 오탐, 6.3).
- **WAIT 2일은 시연 중 기다릴 수 없다.** 시연 시간 안에 분기를 보여야 하면 WAIT 를 1분으로 줄인 사본을 따로 만든다(빌더 최소값 1분). 실제 대기는 엔진 주기 때문에 최대 약 1분 더 걸린다.
- 시연 전에 클릭 고객·미클릭 고객·구매액 10만 원 이상/미만 고객이 각각 1명 이상 있도록 고객 데이터를 맞춰 둔다. 구매액은 고객 상세의 구매 등록으로 올린다.
